Engineering Decisions

Why certain production choices were made during this migration.

IAM Role over Access Keys

Used EC2 instance roles instead of hardcoded AWS credentials for secure ECR authentication.

Docker Group Permissions

Granted Jenkins Docker permissions at the operating system level instead of inside the pipeline.

Official Docker Repository

Installed Docker CE from Docker's repository instead of Ubuntu's default package.

Hosted GitHub Runners

Designed the migration around GitHub-hosted runners to minimize infrastructure maintenance.
